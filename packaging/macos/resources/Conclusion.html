Ready to open BatteryBridge

Open Finder → Applications → BatteryBridge. No Terminal commands are needed.

The app should show your saved charge policy instead of “Read-only mode”. Set a stop percentage and choose “Apply limit”. Hardware errors appear in the app if the firmware refuses a change.

Closing the app does not stop the charging service. Use “Turn off” in BatteryBridge to restore normal charging.

This is an unsigned developer preview. For installation or hardware issues, use the project’s GitHub Issues page and attach a reviewed compatibility report generated in the app.
